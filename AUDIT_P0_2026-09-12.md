# Audit source MNHUT Platform và kết quả P0

Ngày audit: 12/09/2026

## Kết luận

Source hiện tại là nền móng có thể tiếp tục, không cần và không được viết lại từ đầu. UI React có chất lượng thị giác tốt, app shell rõ ràng và phù hợp hướng Cyber Professional. Backend đã có dữ liệu SQLite thật cho một số luồng nền. Trước audit, source chưa build được, chưa có lockfile, Tauri thiếu cấu hình dev server, backend lỗi khi import với FastAPI đã pin và hợp đồng cập nhật Kanban lệch giữa frontend và API.

P0 đã sửa các lỗi có bằng chứng. Frontend typecheck và production build thành công; backend migration/API test thành công; entrypoint phát triển có kiểm tra dependency; giao diện đã được mở và kiểm tra ở 1366 x 768 với backend thật. Sau audit ban đầu, Rust GNU đã được cài để dùng MinGW hiện có; Tauri release, FastAPI sidecar và installer NSIS đều đã build và smoke test thật.

## Chức năng hiện có

- App shell, sidebar, breadcrumb, tab, dark/light, Ctrl K và responsive.
- Dự án, nhiệm vụ, Kanban trạng thái và lỗi cơ bản qua API/SQLite.
- File scan và metadata index có giới hạn bản ghi.
- Terminal chạy argv với `shell=False` và chặn nhóm lệnh phá hủy trực tiếp.
- Đọc metric hệ thống, danh sách tiến trình và cổng từ backend; metric hệ thống native Tauri.
- Mở/đóng nhiều cửa sổ cùng app qua Tauri, có fallback cửa sổ trình duyệt khi chạy web.
- Lưu quy trình, ADR, ứng tuyển, thông báo, cài đặt và lịch sử chạy ở mức API nền.
- Migration tuần tự và khóa ngoại SQLite.

## Lỗi có bằng chứng đã sửa trong P0

1. Frontend thiếu `@types/react` và `@types/react-dom`, khiến TypeScript báo hàng loạt lỗi JSX.
2. Không có `package-lock.json`, nên dependency không tái lập được.
3. Tauri không có `build.devUrl`, `beforeDevCommand` và `beforeBuildCommand`; lệnh CLI đặt `--config` sai vị trí.
4. Hai endpoint HTTP 204 trả qua JSON response mặc định khiến FastAPI ném `AssertionError` ngay lúc import.
5. Frontend cập nhật Kanban bằng query string trong khi backend nhận JSON body.
6. Kết nối SQLite không được đóng; test khóa file database trên Windows.
7. Lỗi mạng `Failed to fetch` lọt ra UI bằng tiếng Anh và trạng thái API luôn báo mất kết nối dù backend hoạt động.
8. Nút `Tạo mới` dùng fallback sai ngữ cảnh trên nhiều trang; hiện chỉ xuất hiện khi có hành vi thật tương ứng.

## Rủi ro đã xác định nhưng chưa sửa ngoài phạm vi P0

- Terminal mới chặn tên lệnh trực tiếp theo blocklist; người dùng vẫn có thể gọi trình thông dịch như `cmd`, PowerShell hoặc Python để đi vòng. P1 phải chuyển sang policy/allowlist theo loại tác vụ, xác nhận và audit log trước khi mở rộng.
- API duyệt/quét tệp nhận đường dẫn tuyệt đối; cần workspace scope, canonical path policy và kiểm thử path traversal ở P1/P3.
- API loopback chưa có session token; cần ghép lifecycle và session local với sidecar trước production.
- Capability Tauri cho cửa sổ động còn dùng wildcard; cần thu hẹp theo nhãn/capability thực tế.
- Nhiều endpoint nền chưa có caller frontend. Chúng giữ trạng thái logic chưa tích hợp, không được tính là chức năng hoàn thành.

## Nguyên nhân app trước đây có thể không chạy hoặc mở sai

- Chưa cài dependency frontend và không có lockfile.
- Python 3.14 không có wheel tương thích với `pydantic-core` đã pin; môi trường dev cần Python 3.11 đến 3.13 hoặc toolchain Rust để tự biên dịch.
- Tauri không biết địa chỉ Vite dev server và không tự chạy build frontend.
- Backend không import được với FastAPI 0.116.1 do khai báo 204 sai.
- API loopback production chưa có session token; đây là việc P1, dù sidecar đã được đóng gói và quản lý vòng đời.
- GNU linker cảnh báo nhiều manifest tài nguyên; binary/installer và smoke test vẫn đạt, nên cần dọn khi chuyển toolchain MSVC.
