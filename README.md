# StudyFlow

Website học tập riêng, responsive và không cần Node/npm/C#.

## Chạy bằng nút Run trong VS Code

1. Mở riêng thư mục `StudyPage` bằng VS Code.
2. Mở file `run.py`.
3. Bấm nút **Run Python File** hoặc nhấn `F5` và chọn **Run StudyFlow Website**.

Website sẽ tự mở trong trình duyệt.

Hoặc chạy một lệnh:

```powershell
py run.py
```
